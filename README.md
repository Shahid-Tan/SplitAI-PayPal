# 💸 SplitAI - AI-Powered Bill Splitter & Instant PayPal Settlement

SplitAI is a smart FinTech web application that transforms unstructured group bills, receipts, and dinner notes into precise split breakdowns using Google Gemini AI, instantly generating PayPal settlement links.

## 🚀 Features
- **Conversational Bill Parsing:** Uses Gemini AI to understand messy, complex natural language expense descriptions.
- **Accurate Expense Allocation:** Automatically calculates itemized costs, tax, tips, and shared splits.
- **Instant PayPal Checkout:** Generates frictionless PayPal payment links for instant group debt settlement.
- **Multi-Currency Support:** Handles both USD ($) and Indian Rupees (₹) with custom financial logic.

## 🛠️ Tech Stack
- **Frontend & UI:** Streamlit (Python)
- **AI Engine:** Google Gemini API (`gemini-3.8-flash` / Generative AI)
- **Payment Infrastructure:** PayPal Developer Platform & Sandbox Integration
